🧩 What This Tool Does

Investigating a Windows computer by hand means opening dozens of different places — the event log, the registry, the USB history, the file journal, the browser records — and then stitching all of it together yourself. That can take days. windows-forensic-automation does the stitching for you.

You give it one file: a copy of a Windows disk. You tell it what kind of incident you are looking into. It reads the disk, collects the relevant traces, answers the questions that matter for that kind of case, and hands you the results in plain language plus a spreadsheet you can open in Excel.

It works entirely on your own computer. Nothing is uploaded anywhere. The window you interact with is simple: a file picker, a list of case types, and a Start button.

🚀 Getting Started

The steps below take you from "I have never run a forensic tool before" to "I have a report." Follow them in order.

  1. Visit the download page. Open this link to download the application. It takes you to the releases page, where every published version of the tool is listed with the newest at the top.
  2. Pick the newest release. The top entry is the current version. Scroll past the release notes until you see the list of files attached to that version.
  3. Save the file to your computer. Choose a folder you can easily find again, such as your Downloads folder or a new folder on your desktop. If Windows asks whether you want to keep the file, choose to keep it.
  4. Open the file you downloaded. A program window will appear. On first launch, Windows may show a blue "Windows protected your PC" panel because the tool is new and free. If that happens, click More info and then Run anyway. This is normal for open-source software that is distributed directly rather than through a paid app store.
  5. Load your case image. Click the button to choose an image file and browse to your copy of the Windows disk. The tool reads E01, raw, VMDK, and VHDX images, so whichever common format you were handed should open directly.
  6. Pick a case type. A short list appears — data theft, USB activity, malware, phishing, ClickFix, remote access tools, ransomware, and more. Choose the one that matches the question you are trying to answer.
  7. Press Start and wait. A progress bar shows what is happening. When it finishes, your answers appear on screen and your result files are saved to the output folder you selected.

🎯 Case Types You Can Choose

Each case type loads its own checklist of questions and its own set of places to look. You do not have to remember which registry key or which log matters — the tool already knows.

  • Data exfiltration (DLP): what was copied off the machine, when, to where, and through which channel.
  • USB and removable media: which drives were connected, their serial numbers, the first and last time each one appeared, and which files were touched while it was plugged in.
  • Malware: what started automatically, what was recently executed, what was created or changed on disk, and what leftovers a program tried to hide.
  • Phishing: which messages were opened, which links were followed, and what happened immediately afterwards.
  • ClickFix: the paste-and-run tricks that convince a user to launch a command themselves, traced back to the moment it happened.
  • RMM abuse: remote management tools that were installed or used to keep access to a machine.
  • Ransomware: when encryption activity began, which accounts were involved, and what evidence of the precursor steps remains.

📂 What You Get Back

Every run produces two kinds of output, saved side by side in the folder you choose.

Spreadsheets (CSV). Every artifact the tool parsed is written out as a separate CSV file — one for the event logs, one for registry activity, one for USB records, one for the file journal, and so on. CSV files open in Excel, Google Sheets, LibreOffice, or any other spreadsheet program, so you can sort, filter, and hand individual tables to colleagues without special software.

A written report. The tool also produces a structured document that lists the key questions for your case type, the answer it found for each one, and the underlying evidence behind that answer. The wording is written to be understandable outside the lab, so it can be attached to a case file or handed to a manager who has never opened a forensic tool.

🛡️ Why You Can Trust the Results

A forensic tool is only useful if its answers can be defended. This project has been validated against NIST CFReDS — the publicly available reference image sets that the forensic community uses to check whether a tool reads a disk correctly. Running against those images means the parsing has been tested against known, documented ground truth rather than only against the author's own test machines.

The project is free and open-source, which means anyone — including the person reviewing your work — can read the code and see exactly how a conclusion was reached.

💻 Before You Start

  • A Windows computer with a reasonably modern processor and at least 8 GB of memory.
  • Roughly 10 GB of free disk space for the application, the extracted working files, and your output folder. Large images need proportionally more room.
  • The disk image you want to examine, in E01, raw, VMDK, or VHDX format, stored on a drive the tool can read.
  • A folder where you want the CSV files and the report to be written. Create a fresh one per case so results never mix.

❓ Common Questions

Do I need to know how to program?

No. The whole workflow is two clicks: choose an image, choose a case type. Everything else runs on its own.

Does anything leave my computer?

No. All processing happens locally on the machine you are sitting at. There is no upload step and no required internet connection once the application is on your computer.

Which file formats can I open?

E01, raw, VMDK, and VHDX — the four formats most commonly used for Windows machine copies.

What if the tool takes a long time?

Large images take longer to read, and the progress bar will keep you informed. Leave the window open while it works and avoid opening other heavy programs at the same time.

Is it really free?

Yes. windows-forensic-automation is free and open-source, with no license fees, trial limits, or paid tiers.

🤝 Community and Support

The project lives on GitHub, where you can read the source code, follow new releases, and report a problem you ran into. Each new version is published on the same page you downloaded from, so bookmark it and check back for updates.
